# Agents

## code-reviewer
Review code changes for correctness, security, and consistency with the project's existing patterns.

## backend-auditor
Search the backend codebase for TODO, FIXME, pass stubs, incomplete implementations, missing route registrations, and broken imports.

## frontend-auditor
Search the frontend codebase for TODO, FIXME, mock/hardcoded data, console.log leaks, missing hook exports in hooks/index.ts, and type mismatches.

## migration-checker
Check whether new models have corresponding route registrations and migrations.
