# Commands

## /local-review
Review all committed changes on the current branch.

## /local-review-uncommitted
Review uncommitted changes in the working tree.

## /check-types
Run typecheck for both backend and frontend.

## /check-types-backend
Run Python type/lint checks on the backend.

## /check-types-frontend
Run TypeScript typecheck on the frontend.

## /audit-backend
Run backend audit: search for TODO, FIXME, pass stubs, and missing route registrations.

## /audit-frontend
Run frontend audit: search for TODO, FIXME, console.log, mock data, and missing hooks exports.
